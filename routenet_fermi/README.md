# RouteNet-Fermi source

`loss_model.py` is an unmodified copy of the model implementation from the
official [RouteNet-Fermi repository](https://github.com/BNN-UPC/RouteNet-Fermi)
at commit `ef72a37bb6f677e149f354f088f5836f29c862b5`.

Only this upstream file is required by the XNDT experiments. The XNDT-adapted
version is kept separately in `xndt/model.py`; the original file in this
directory must remain unchanged.
